# Chess piece assets

- `assets/chess/pieces/*.png` — White silhouettes from
  [Flutter-Libya/Full_Functional_Chess_Game](https://github.com/Flutter-Libya/Full_Functional_Chess_Game)
  (MIT, see `LICENSE`), used for the "classic" style.

- `new pieces/new white/*.png` and `new pieces/new black/*.png` — the default
  flat piece set, sourced from
  [baticpro/flutter-chess-game-bloc](https://github.com/baticpro/flutter-chess-game-bloc)
  `assets/images/figures/`, as requested. The black set is darkened slightly at
  build time for contrast on light squares.
